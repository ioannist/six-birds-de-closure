Brouwer's fixed-point theorem, used in \Cref{thm:orbits}, comes from a
ported and transitively checked development pinned in
\texttt{lean/\allowbreak Gametheory/\allowbreak PROVENANCE.json}. Exact certificates for the
orbit classification and the window brackets are generated by scripts in
the repository and checked by the Lean kernel; a few auxiliary
certificates computed outside Lean are marked as exact computations
where they are used.

\textbf{Verification record.} A full registered build of the development
completed with 11,775 build jobs. It was followed by 20,798 registered
declaration and type queries and a cumulative audit of 32,574 queries
for the axioms the proofs use. The only axioms that occur are
\texttt{propext}, \texttt{Classical.choice} and \texttt{Quot.sound};
there are no \texttt{sorry} placeholders, custom axioms or native-code
trust extensions. The receipts are in
\texttt{results/\allowbreak native\_\allowbreak registered\_\allowbreak final\_\allowbreak verification\_\allowbreak 2026-\allowbreak 10-\allowbreak 06/\allowbreak }.
The recorded full run of the Python test suite passed 127 tests, before
later corrected-helper and deterministic line-ending integrations; a
subsequent focused check passed four tests. No full-suite receipt exists
for the final Python snapshot. These records are in
\texttt{results/\allowbreak ground\_\allowbreak state\_\allowbreak 2026-\allowbreak 10-\allowbreak 02/\allowbreak verification.json}.

\hypertarget{c.3-provenance-of-the-lattice-model}{%
\subsection{Provenance of the lattice
model}\label{c.3-provenance-of-the-lattice-model}}

The lattice model originates in another Six Birds repository. Its
required source files were copied into \texttt{external/\allowbreak step54\_\allowbreak repro/\allowbreak }
with a manifest recording source paths and SHA-256 hashes, with source
commits where recorded (the catalog file from the Foundations series has
none); the hashes match, and one file differs from its source only by a
disclosed path relocation. The sweep was re-run on this project's
hardware, and an independently written classifier, sharing no code with
the source, recomputed pass or fail for every offset and coupling from
the regenerated residual tables. All rows agree with the source
artifacts.

\hypertarget{c.4-recomputing-the-geometry-audits}{%
\subsection{Recomputing the geometry
audits}\label{c.4-recomputing-the-geometry-audits}}

The geometry audits run without a Boltzmann solver; an optional solver
import was made lazy, and the acceptance suite was executed with that
import blocked. With the pinned requirements in
\texttt{results/\allowbreak DE\_\allowbreak audit\_\allowbreak repro/\allowbreak }:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \texttt{pytest\ tests/\allowbreak test\_\allowbreak de\_\allowbreak audit.py} passes (4 tests);
\item
  \texttt{python\ scripts/\allowbreak de\_\allowbreak audit\_\allowbreak validate.py\ -\allowbreak \/\allowbreak -\allowbreak results-\allowbreak dir\ results/\allowbreak DE\_\allowbreak audit}
  re-derives the verdicts with no mismatch;
\item
  \texttt{python\ scripts/\allowbreak de\_\allowbreak audit\_\allowbreak repro\_\allowbreak smoke.py\ -\allowbreak \/\allowbreak -\allowbreak tolerance-\allowbreak chi2\ 5.0}
  performs a reduced optimizer refit of the B1 likelihood and reproduces
  the stored best-fit \(\chi^2\) values within tolerance
  (\(\Delta\chi^2=-0.008\) for \(\Lambda\)CDM and \(-0.63\) for the
  rewrite).
\end{enumerate}

These are smoke-level comparisons, not a full replication of the
posteriors. A skeptical reader can start with the test suites and
validators (seconds), then the model builds (minutes), the Lean build
(hours on one machine) and the full audit battery (hours, dominated by
nested sampling).
