# Guarded return to exception-aware source execution

The total mathematical native update is used for iteration and calculus. The
literal normalization subroutine instead rejects a norm at most its threshold.
The new return theorem connects these representations without attributing a
total division formula at zero to an executed source state.

For an arbitrary raw update, `GroundSourceExecutionReturn.run_guarded` proves
that the normalization-exception execution returns the total normalized map's
Nth iterate whenever all normalization guards before N hold. The converse is
also proved: every successful execution returns precisely that iterate and
earns every guard in its finite prefix. `run_iff_guards` gives their equivalence.
The guards are evaluated along the actual total orbit, not an independently
chosen sequence. Update zero returns the supplied initial state and has an
empty prefix, as required. No nonnegative-threshold assumption is needed for
these branch/equality statements; norm-one bounds retain that assumption in
the earlier normalization module.

The native specializations use exactly `nativeMixed` and `NativeLegal`. The
source's inner normalization of the unit ground selector also returns that same
candidate when the threshold is below one. This uses the independently proved
ground selector's unit norm, rather than assuming an eigensolver returns a
normalized witness. The original double initialization and its already proved
two normalization guards remain in `GroundOriginalSeed.initial`.

`GroundOriginalCycleExecution.coupling20_execution` and
`coupling30_execution` then supply a returned state for every finite update
count of the actual original complex seed, equality with the earned native
orbit, both original source guards at that state and unit norm. The populated
original-seed cycle-return theorems discharge the normalization premises.
There is no execution-success, entry, orbit-legality, real-seed or convergence
hypothesis supplied by the caller. The theorem covers all finite truncations,
including zero; it does not represent an infinite Python computation.

This is a direct source-domain return for the previously constructed cycles.
Their quantitative bounds remain distinct: coupling20 has density gap >1/4
and eventual update gap >1/8; coupling30 has >9/20 and >9/40. Normalization
success is compatible with nonconvergence and periodic limiting behavior.

The `Option` execution models the source's normalization exception as no
returned state. Other earlier runtime exceptions and the numerical eigenvector
backend are outside this interface. The connection is to the exact mathematical
native map already used in the source proofs, with its original phase convention
and threshold. It does not certify IEEE arithmetic or suppress a rejected
normalization. The finite-prefix converse and previously proved rejected-zero
and absorbing-failure properties control this possible totalization loophole.
